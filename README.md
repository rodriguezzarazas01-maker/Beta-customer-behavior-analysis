# Β Proyecto Beta | Análisis del Comportamiento de Clientes

## Descripción

Store 1 buscaba profundizar su conocimiento sobre el comportamiento de sus clientes con el fin de desarrollar campañas de marketing más efectivas y personalizadas. Para ello, se llevó a cabo un proceso de análisis orientado a transformar datos de clientes en información útil para la toma de decisiones comerciales.

## Objetivos

- Analizar patrones de consumo de los clientes.
- Estandarizar y preparar la información para su análisis.
- Identificar segmentos de clientes con características similares.
- Detectar consumidores de alto valor.
- Analizar preferencias de compra por categoría.
- Apoyar estrategias de marketing segmentado y fidelización.

## Herramientas utilizadas

- Python
- Jupyter Notebook
- Análisis de datos
- Segmentación de clientes
- Transformación de datos
- Análisis de consumo

## Metodología

- Limpieza y estandarización de registros.
- Normalización de categorías de productos.
- Consolidación de ingresos y gastos.
- Segmentación por variables demográficas.
- Identificación de clientes de alto valor.
- Clasificación por preferencias de compra.
- Construcción de grupos de clientes para acciones comerciales específicas.

## Principales hallazgos

- Se obtuvo una base de datos consistente y preparada para análisis de negocio.
- Fue posible identificar segmentos de clientes según edad, preferencias y nivel de gasto.
- Se detectaron clientes con alto potencial comercial mediante la combinación de variables demográficas y de consumo.
- Se generaron agrupaciones útiles para campañas de marketing más personalizadas.

## Archivo principal

- `beta_customer_behavior_analysis.ipynb`

## Conclusión

Como resultado del proceso de preparación y análisis, se obtuvo una visión más profunda del comportamiento de los clientes de Store 1. La información fue limpiada y estandarizada para garantizar su calidad, permitiendo posteriormente identificar patrones de consumo, calcular ingresos generados por los clientes y segmentar grupos de usuarios según sus características demográficas e intereses de compra. Estos hallazgos proporcionan una base sólida para desarrollar campañas de marketing más personalizadas, fortalecer estrategias de fidelización y respaldar futuras decisiones comerciales basadas en datos.
